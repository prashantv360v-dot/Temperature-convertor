# Temperature Converter 🌡️

A Simple, responsive, and real-time  **Temperature Converter** web application bulid using **HTML, CSS AND JAVASCRIPT** .
It allows users to convert temperature values seamlessly between **Celsius(°C), Fahrenheit(°F) and Kelvin (K)**.

## Built With

**HTML** - Structure and input elements
**CSS** - Styling, flexbox/grid layout, and responsive design
**JAVASCRIPT** - DOM manipulation and math conversion formulas

## How to run Locally
1- Clone the repository
2- Navigate to the project folder
3- Open the project:
    Double-click 'index.html' to open it in your default web browser, 
    (OR)
    Use a live server extension (like vs code Live Server) for a local development preview.
